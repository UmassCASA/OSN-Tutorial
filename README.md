# Open Storage Network Tutorial

A guided notebook covering OSN data access, Globus browsing, local staging, remote analysis, and uploading data onto OSN.

## Download and Open

1. On the GitHub repository's main page, select **Code → Download ZIP**.
2. Extract the ZIP archive, then open the folder containing this tutorial.
3. Keep `OSN_Tutorial.ipynb`, `environment.yml`, and the `Screenshots/` folder together. The screenshots are needed to display images in the notebook.
4. Follow the **Python setup** section in the notebook to create the conda environment and select its Jupyter kernel. Run code cells in order.

You can also read the notebook directly on GitHub without running it.

Most exercises require no OSN credentials, but uploading requires your own **read/write (RW) access key and matching secret key**. The staging exercise downloads approximately **1.52 GB** into `./Data` on the computer running the notebook.
